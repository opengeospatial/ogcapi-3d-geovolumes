== Media Types

A table of the media types relevant to this standard follows.

[#media-types,reftext='{table-caption} {counter:table-num}']
.Media Types relevant to OGC API - 3D GeoVolumes
[width="90%",cols="2,4"]
|====
^|*media type*                        ^|*description*
|`text/html`                           |Supported to present browser-friendly metadata resources
|`application/json`                    |Used for landing page, conformance, collection description, OGC API - Tiles tilesets list and tilesets metadata
|`application/3dtiles+json`            |Used for 3D Tiles Bounding Volume Hierarchy tilesets
|`application/vnd.esri.i3s.json+gzip`  |Used for i3s Tiles Bounding Volume Hierarchy tilesets
|`model/gltf-binary`                   |Used for 3D Models (whether batched 3D models, referenced 3D models, or glTF content linked from 3D Tiles 1.1+ tilesets)
|`text/geo+json`                       |Tiled Point Vector Data GeoJSON encoding option for tiles referencing 3D models
|`application/vnd.mapbox-vector-tile`  |Tiled Point Vector Data Mapbox Vector Tiles encoding option for tiles referencing 3D models
|====
